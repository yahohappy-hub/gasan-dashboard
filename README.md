# 가산가소가판 민감도분석 대시보드

호남 분산특구 연계형 **가산가소가판(家産家消家販)** 사업모델의 CAPEX/OPEX/수익 민감도분석 인터랙티브 대시보드입니다.

## 주요 기능
- **CAPEX/OPEX**: PV, ESS, 충전기, AMI 비용 파라미터 실시간 조정
- **수익구조**: 시나리오 A~D별 수익원 분해 (자가소비, TOU, V2G, DR, NWA, P2P)
- **민감도분석**: 6개 핵심 변수의 투자회수기간·NPV 변동 + 토네이도 차트
- **현금흐름**: 25년 누적 현금흐름 그래프 및 연도별 상세 테이블

## 기술 스택
- React 18 (CDN, Babel 실시간 변환)
- 단일 HTML 파일 (서버 불필요)
- 라이트/다크 모드 자동 대응
